Claude Chat Widget — UI showcase

This is what your visitors see. A floating launcher, a themed chat panel, streaming replies. Vanilla JS, ~6 KB, zero build step.

What you're looking at

Click the balloon in the bottom-right corner to open the widget UI. It's the exact same widget.js a real deployment uses — this static demo just has no backend wired up, so sending a message will show a connection error. The point is to see the UI, theming, and interactions.

To run the real thing

1. composer require grodev/claude-chat-widget

2. Set ANTHROPIC_API_KEY in your environment

3. Drop widget.js on any page — done. The proxy keeps your key on the server; the browser never sees it.
